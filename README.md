# Apple Landing Page 🍎

A responsive Apple-style landing page built to practice modern UI design and clean layouts.

## 🚀 Features
- Responsive design (mobile, tablet, desktop)
- Clean Apple-inspired UI
- Smooth layout and spacing
- Pixel-perfect sections

## 🛠 Tech Stack
- HTML
- Tailwind CSS
- JavaScript

## 🌐 Live Demo
https://apple-15-pro-green.vercel.app/

## 📚 What I Learned
- Building responsive layouts
- Improving UI consistency
- Writing clean, structured HTML & CSS

## 📦 Installation
npm install

## ▶️ Run Locally
npm run dev
